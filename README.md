# ✨ MANIFEST! Monthly

**A hand-painted manga magazine for a more intentional life.**

Explore the worlds of **luck 🍀, wealth 💰, and happiness 🌸** through interactive pages, practical rituals, and insights from some of the most influential manifestation teachers.

🌐 **Live demo:** [manifest-five-murex.vercel.app](https://manifest-five-murex.vercel.app)

---

## 📖 Inside the Magazine

- 🍀 **Luck** — Train your awareness and spot hidden opportunities
- 💰 **Wealth** — Build an abundance mindset and turn ideas into action
- 🌸 **Joy** — Create happiness through gratitude, kindness, and small rituals
- 🎓 **Teacher Profiles** — Explore ideas from Neville Goddard, Bob Proctor, Louise Hay, and more
- ✨ **Final Ritual** — Turn reflection into a personal practice

---

## 🎮 Take Control

Turn the pages naturally using:

- 🖱️ **Clicking** the open magazine
- 👆 **Touch and swipe** gestures
- ⌨️ **Arrow keys** for keyboard navigation
- 🔄 **Page controls** for direct movement

## 🚀 Run Locally

```bash
git clone https://github.com/euro-tree/manifest.git
cd manifest
corepack enable
pnpm install
pnpm dev
```

Open **http://localhost:3000** and start flipping through the issue.
